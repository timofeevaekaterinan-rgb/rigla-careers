# Ригла — карьерный лендинг (пресейл)

Вёрстка по макету: 1920 / 1440 / 1200 / 360. Чистые HTML + CSS + JS, без сборки.

- `index.html`, `styles.css`, `app.js`
- `img/` — фото (сгенерированы нейросетью), `video/anna.mp4` — ролик для первого экрана
- Десктоп в rem от 1920 (1440 = 1920 × 0,75), мобильная раскладка < 1200 px

Демо-материал для пресейла, не для индексации.
